# Travel Planner 设计系统

## 使用场景

这是一个以规划和保存旅行为目标的 Operate 界面。视觉应帮助用户快速完成“选地点、排时间、看路线、保存行程”，而不是模拟营销页或社交产品。

## 设计方向

- 主题：浅色少女粉手账感，地图保持真实色彩和语义可读性。
- 密度：中等。地点和时间线可扫读，操作始终可见。
- 动效：仅用于状态切换、卡片按压和路线生成反馈。尊重 `prefers-reduced-motion`。
- 图标：统一使用项目已有的 `lucide-react`，不手写结构性 SVG。

## 语义 Token

| 用途 | Token | 当前值 |
| --- | --- | --- |
| 页面底色 | `--travel-bg` | `#fff9fb` |
| 表面 | `--travel-surface` | `rgb(255 255 255 / 90%)` |
| 主操作 | `--travel-pink-600` | `#e94d80` |
| 选中态 | `--travel-border-strong` | `rgb(238 145 178 / 52%)` |
| 步行路线 | `--travel-route-walking` | `#ef668f` |
| 公交地铁 | `--travel-route-transit` | `#4e99a0` |
| 错误 | `--travel-danger` | `#bf4864` |
| 键盘焦点 | `--travel-focus` | `#9a3560` |

粉色只表达品牌、选中、步行和主要操作。公交、警告、错误保留独立语义色。

## 版式规则

- 1440px 及以上：侧栏、地点库、时间线、地图同时可见，地图可固定在视口内。
- 768-1099px：地点库和时间线并列，地图下移为完整区域。
- 767px 及以下：地图为底层画布，行程、地点、地图用三标签抽屉切换；操作栏固定在抽屉底部。
- 所有卡片标题和地址必须可折行，使用 `overflow-wrap: anywhere`，不可依赖省略号隐藏关键信息。
- 触控控件最小高度 44px，按钮之间至少留出 8px 触控间距。

## 形状与层级

- 容器圆角使用 12px、18px、24px 三档。
- 按钮可使用全圆角，内容卡片不使用胶囊形。
- 使用一层浅粉色阴影或边框来表达层级，不同时堆叠重边框和重阴影。

## 无障碍基线

- 键盘焦点必须可见。
- 仅以颜色不能传达关键状态。
- 所有图标按钮必须有文字或 `aria-label`。
- 减少动态效果时关闭花瓣装饰、过渡和 Rive 的非必要画面。
